    這個系統在做什麼

    把臺灣期貨交易所公開的台指選擇權（TXO）未平倉、成交與三大法人資料，整理成一眼能讀的圖表，協助判斷主力看待的支撐與壓力區間。

    指標定義

    Call 牆 / Put 牆
    該合約未平倉量最大的買權 / 賣權履約價。賣方通常是資金較大的一方，因此 Call 牆常被視為壓力、Put 牆視為支撐。
    最大痛點（Max Pain）
    讓所有買方合計獲利最少（賣方賠付最少）的結算價，以各履約價未平倉逐點計算。
    預期波動
    以價平跨式（ATM Call＋Put）權利金反推市場隱含的到期前一個標準差範圍：跨式價 ÷ 0.8。
    區間內機率
    以上述標準差假設常態分佈估算，僅供比較策略用，實際行情有肥尾風險。
    增減
    最新交易日與前一交易日未平倉量之差，代表新增或平倉的部位。

    資料來源與更新頻率

    • 未平倉、三大法人：期交所每日盤後公布（經 FinMind 開放資料 API 取得），本系統每 30 分鐘檢查更新。
    • 即時價量（日盤＋夜盤）：期交所行情資訊網，每 15 秒更新。即時未平倉交易所不提供，故 OI 為前一交易日盤後值。
